# 第4阶段：普通下单与订单生命周期

## 1. 阶段目标

本阶段使用 Spring Boot、MyBatis-Plus 和 MySQL 完成普通下单流程，重点理解事务和订单状态，不处理高并发。

接口实现顺序：

```text
1. 创建用户
2. 查询用户
3. 创建订单
4. 查询订单详情
5. 查询用户订单列表
6. 支付订单
7. 取消订单并恢复库存
```

只有前一个接口完成并验收后，才进入下一个接口。

## 2. 分层职责边界

| 层 | 类 | 职责 |
| --- | --- | --- |
| 接口层 | `AppUserController`、`TicketOrderController` | 接收DTO、调用Service、返回VO |
| 业务层 | `AppUserService`、`TicketOrderService` | 用户规则、订单状态机、库存与订单事务编排 |
| 数据访问层 | `AppUserMapper`、`TicketOrderMapper`、`TicketStockMapper` | 单表查询和更新 |
| 配置层 | 现有MyBatis-Plus配置 | 不新增订单业务Bean |
| 异常层 | 全局异常处理 | 将不存在、状态冲突等异常转换为响应 |

下单调用链：

```text
POST /api/orders
  ↓
TicketOrderController
  ↓
TicketOrderService.createOrder()  ← @Transactional
  ├─ AppUserMapper查询用户
  ├─ TicketEventMapper查询活动
  ├─ TicketStockMapper查询并修改库存
  └─ TicketOrderMapper插入订单
```

事务只能放在Service，不放在Controller或Mapper。

## 3. 状态设计

### 用户状态

```text
ACTIVE     正常
DISABLED   禁用
```

### 订单状态

```text
PENDING     待支付
PAID        已支付
CANCELLED   已取消
EXPIRED     已超时
```

第一版允许的订单状态变化：

```text
PENDING → PAID
PENDING → CANCELLED
```

禁止：

```text
PAID → CANCELLED
CANCELLED → PAID
```

## 5. 接口1：创建用户

### 请求

```http
POST /api/users
```

```json
{
  "username": "张三",
  "phone": "13800138000"
}
```

### DTO校验

```text
username：非空，最长50
phone：非空，格式正确，最长20
```

### Service流程

```text
1. 根据phone检查是否存在
2. 存在则抛出“手机号已注册”
3. 创建状态为ACTIVE的用户
4. Mapper.insert
5. 转换为UserVO
```

数据库唯一索引是最终保护，Service预检查负责友好提示。

### 验收

- 正常创建并返回用户ID。
- 重复手机号失败。
- 请求不能指定用户状态和ID。

## 6. 接口2：查询用户


Service负责不存在判断，Controller只接收路径参数。

### 验收

- 存在用户返回VO。
- 不存在用户返回统一业务错误。
- 不返回未来可能加入的密码等敏感字段。

## 7. 接口3：创建普通订单

### 请求

```http
POST /api/orders
```

```json
{
  "userId": 1,
  "stockId": 10
}
```

第一版固定一人一票，DTO中不要提供 `quantity`，避免客户端绕过规则。

### Controller职责

```java
@PostMapping
public ApiResponse<TicketOrderVO> create(
        @Valid @RequestBody CreateTicketOrderRequest request) {
    return ApiResponse.success(ticketOrderService.createOrder(request));
}
```

### Service事务流程

```text
1. 查询用户，必须存在且为ACTIVE
2. 查询票档，必须存在
3. 查询活动，必须存在且为ON_SALE
4. 当前时间必须在售票时间内
5. 检查用户是否已购买同一票档
6. 检查availableStock > 0
7. 将availableStock减1并updateById
8. 生成唯一orderNo
9. 保存活动名、票档名、价格快照
10. 状态设置为PENDING
11. 插入订单
12. 返回订单VO
```

整个方法使用：

```java
@Transactional(rollbackFor = Exception.class)
```

### 订单号

订单号不能使用数据库ID替代。初学版可以使用：

```text
日期时间 + 随机片段
```

仍由数据库唯一索引 `uk_ticket_order_order_no` 做最终保护。

### 为什么保存快照

订单中保存：

```text
eventName
ticketType
unitPrice
totalAmount
```

即使活动名称或价格以后修改，历史订单仍显示下单时内容。

### 验收

- 正常下单后库存减1。
- 订单状态为PENDING。
- 用户禁用、活动未上架、超出时间都不能下单。
- 同一用户重复购买失败。
- 插入订单失败时库存修改被事务回滚。

本阶段此实现只适合低并发，下一阶段会替换库存更新方式。

## 9. 接口5：查询用户订单列表

```http
GET /api/users/{userId}/orders?page=1&size=10&status=PENDING
```

Service流程：

```text
1. 确认用户存在
2. 查询user_id
3. status存在时增加状态条件
4. 按create_time倒序
5. 返回分页VO
```

### 验收

- 支持状态筛选。
- 分页总数正确。

## 10. 接口6：支付订单

```http
POST /api/orders/{orderNo}/pay
```

当前阶段不接真实支付平台，只模拟状态变化。

Service事务流程：

```text
1. 查询订单
2. 必须是PENDING
3. 修改为PAID
4. 设置payTime
5. 更新订单
6. 返回最新订单VO
```

### 验收

- 待支付订单可以支付。
- 已支付订单重复支付被拒绝。
- 已取消订单不能支付。

## 11. 接口7：取消订单并恢复库存

```http
POST /api/orders/{orderNo}/cancel
```

Service必须在同一事务中完成：

```text
1. 查询订单
2. 必须是PENDING
3. 查询票档
4. availableStock加1
5. 更新票档
6. 订单状态改为CANCELLED
7. 设置cancelTime
8. 更新订单
```

如果订单更新失败，库存恢复也必须回滚。

### 验收

- 取消后库存恢复1。
- 已支付订单不能取消。
- 已取消订单不能重复恢复库存。
- 任意一步失败时事务整体回滚。

```java
package com.example.flashticket.service;
import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.example.flashticket.dto.OrderDtos.CreateUserRequest;
import com.example.flashticket.entity.AppUser;
import com.example.flashticket.exception.BusinessException;
import com.example.flashticket.mapper.AppUserMapper;
import com.example.flashticket.vo.OrderVos.UserVo;
import org.springframework.stereotype.Service;

@Service
public class AppUserService {
    private final AppUserMapper mapper;
    public AppUserService(AppUserMapper mapper) { this.mapper = mapper; }
    public UserVo create(CreateUserRequest r) {
        if (mapper.selectCount(new LambdaQueryWrapper<AppUser>().eq(AppUser::getPhone, r.phone())) > 0)
            throw new BusinessException(409, "手机号已注册");
        AppUser u = new AppUser(); u.setUsername(r.username()); u.setPhone(r.phone()); u.setStatus(1);
        mapper.insert(u); return toVo(u);
    }
    public UserVo get(Long id) { return toVo(requireUser(id)); }
    public AppUser requireUser(Long id) {
        AppUser u = mapper.selectById(id);
        if (u == null) throw new BusinessException(404, "用户不存在");
        if (u.getStatus() != 1) throw new BusinessException(400, "用户已禁用");
        return u;
    }
    private UserVo toVo(AppUser u) { return new UserVo(u.getId(), u.getUsername(), u.getPhone(), u.getStatus()); }
}
```

`src/main/java/com/example/flashticket/service/TicketOrderService.java`

```java
package com.example.flashticket.service;
import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.example.flashticket.dto.OrderDtos.CreateOrderRequest;
import com.example.flashticket.entity.*;
import com.example.flashticket.exception.BusinessException;
import com.example.flashticket.mapper.*;
import com.example.flashticket.vo.OrderVos.OrderVo;
import java.util.*;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class TicketOrderService {
    private final TicketOrderMapper orderMapper;
    private final TicketStockMapper stockMapper;
    private final TicketEventMapper eventMapper;
    private final AppUserService userService;
    public TicketOrderService(TicketOrderMapper orderMapper, TicketStockMapper stockMapper,
            TicketEventMapper eventMapper, AppUserService userService) {
        this.orderMapper = orderMapper; this.stockMapper = stockMapper;
        this.eventMapper = eventMapper; this.userService = userService;
    }
    @Transactional
    public OrderVo create(CreateOrderRequest r) {
        userService.requireUser(r.userId());
        TicketStock stock = stockMapper.selectById(r.stockId());
        if (stock == null) throw new BusinessException(404, "票档不存在");
        TicketEvent event = eventMapper.selectById(stock.getEventId());
        if (event == null || event.getStatus() != 1) throw new BusinessException(400, "活动未上架");
        if (stock.getAvailableStock() <= 0) throw new BusinessException(409, "库存不足");
        stock.setAvailableStock(stock.getAvailableStock() - 1);
        stockMapper.updateById(stock);
        TicketOrder order = new TicketOrder();
        order.setOrderNo(UUID.randomUUID().toString().replace("-", ""));
        order.setUserId(r.userId()); order.setEventId(event.getId()); order.setStockId(stock.getId());
        order.setEventName(event.getName()); order.setTierName(stock.getTierName());
        order.setAmount(stock.getPrice()); order.setStatus(0); orderMapper.insert(order);
        return toVo(order);
    }
    public OrderVo get(Long id) { return toVo(requireOrder(id)); }
    public List<OrderVo> listByUser(Long userId) {
        userService.requireUser(userId);
        return orderMapper.selectList(new LambdaQueryWrapper<TicketOrder>()
                .eq(TicketOrder::getUserId, userId).orderByDesc(TicketOrder::getId))
                .stream().map(this::toVo).toList();
    }
    @Transactional
    public OrderVo pay(Long id) {
        TicketOrder order = requireOrder(id);
        if (order.getStatus() != 0) throw new BusinessException(400, "只有待支付订单可以支付");
        order.setStatus(1); orderMapper.updateById(order); return toVo(order);
    }
    @Transactional
    public OrderVo cancel(Long id) {
        TicketOrder order = requireOrder(id);
        if (order.getStatus() != 0) throw new BusinessException(400, "只有待支付订单可以取消");
        order.setStatus(2); orderMapper.updateById(order);
        TicketStock stock = stockMapper.selectById(order.getStockId());
        stock.setAvailableStock(stock.getAvailableStock() + 1); stockMapper.updateById(stock);
        return toVo(order);
    }
    public TicketOrder requireOrder(Long id) {
        TicketOrder order = orderMapper.selectById(id);
        if (order == null) throw new BusinessException(404, "订单不存在");
        return order;
    }
    private OrderVo toVo(TicketOrder o) {
        return new OrderVo(o.getId(), o.getOrderNo(), o.getUserId(), o.getEventId(), o.getStockId(),
                o.getEventName(), o.getTierName(), o.getAmount(), o.getStatus(), o.getCreatedAt());
    }
}
```
